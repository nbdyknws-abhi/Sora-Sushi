# Sora Sushi Experience

Welcome to the **Sora Sushi Experience** repository! This project is a modern, high-end web application built for a premium Japanese restaurant, showcasing an exquisite digital dining experience with a stunning glassmorphism design, responsive layout, and beautiful 3D branding.

## 🚀 Features

- **Premium Design Aesthetics**: Built with high-end luxury styling, featuring dark mode, glassmorphism, and custom typography.
- **Dynamic UI**: Smooth hover effects, micro-animations, and a sticky scroll-aware navigation bar.
- **Responsive Layout**: Perfectly adapted for all devices, from mobile screens to large desktop monitors.
- **Modern Tech Stack**: Powered by React, Vite, Tailwind CSS, and TypeScript for blazing-fast performance and excellent developer experience.

## 🛠️ Tech Stack

- **Framework**: React / Vite / @tanstack/start
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Package Manager**: npm (or bun)

## 📦 Installation

To get the project up and running on your local machine, follow these steps:

1. **Clone the repository** (or download the source):
   ```bash
   git clone <repository-url>
   cd "Sora Sushi Experience"
   ```

2. **Install dependencies**:
   Make sure you have Node.js installed, then run:
   ```bash
   npm install
   ```

## 💻 Development

To start the local development server with hot-module-reloading (HMR):

```bash
npm run dev
```

The application will be available at `http://localhost:3000` (or the port specified in your terminal).

## 🏗️ Production Build

To build the application for production, run:

```bash
npm run build
```

This will generate an optimized production build in the `dist` folder. 

You can preview the built application locally using:
```bash
npm run start
```

## 📁 Project Structure

- `src/` - Contains the main source code for the application.
  - `routes/` - Defines the application's routing and main views (e.g., `index.tsx`, `__root.tsx`).
  - `components/` - Reusable UI components.
  - `assets/` - Static assets including images, fonts, and the 3D logo.
- `dist/` - The compiled production-ready output.
- `public/` - Public facing assets.
